# Web de Lacteoca (lacteoca.com)

Rama independiente de la app Genius Keeper. Solo contiene la página web pública de Lacteoca.

- `sitio/` es la web tal cual se publica (index.html + fotos).
- Cada push a esta rama la publica en un sitio propio de Firebase Hosting dentro del proyecto `geniuskeeper-36553`.
- No toca la app, las reglas ni las funciones de Genius Keeper: esos despliegues solo corren desde `main`.
